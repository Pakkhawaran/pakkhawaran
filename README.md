### 👩‍💻 ข้อมูลส่วนตัวและประวัติการศึกษา (About Me)

สวัสดีค่ะ ดิฉัน **นางสาวภัควรรณ อินทสุวรรณ (ยูจีน)** ปัจจุบันกำลังศึกษาอยู่ชั้นปีที่ 2 **สาขาวิชาเทคโนโลยีสารสนเทศ (Information Technology)** คณะศิลปศาสตร์และวิทยาศาสตร์ **มหาวิทยาลัยเกษตรศาสตร์**

ดิฉันมีความสนใจอย่างยิ่งในด้าน **การเขียนโค้ดและการพัฒนาซอฟต์แวร์ (Coding & Software Development)** โดยมุ่งเน้นการพัฒนาเว็บแอปพลิเคชัน การออกแบบโครงสร้างฐานข้อมูล และการประยุกต์ใช้เทคโนโลยีสมัยใหม่เพื่อแก้ไขปัญหาอย่างเป็นระบบ นอกจากนี้ ดิฉันยังให้ความสำคัญกับการเรียนรู้ภาษาโปรแกรมมิงและเครื่องมือใหม่ๆ อยู่เสมอ เพื่อพัฒนาทักษะทางวิชาชีพให้ก้าวทันเทคโนโลยีในปัจจุบัน

- 🎓 **สถาบันการศึกษา:** สาขาวิชาเทคโนโลยีสารสนเทศ มหาวิทยาลัยเกษตรศาสตร์
- 💻 **ความสนใจหลัก (Core Interests):** Full-Stack Web Development, Software Engineering, Database Management และ Data Analytics[cite: 1]
- 🌱 **การเรียนรู้เพิ่มเติม (Currently Learning):** กำลังศึกษาและฝึกฝนภาษาโปรแกรมมิงและเฟรมเวิร์กใหม่ๆ ได้แก่ `Python`, `JavaScript (ES6+)`, `React`, `Node.js` และ `SQL`[cite: 1]
- 🎯 **เป้าหมายทางวิชาชีพ (Career Objective):** มุ่งมั่นพัฒนาศักยภาพผ่านการลงมือทำโครงงานจริง และกำลังเตรียมความพร้อมสำหรับการฝึกประสบการณ์วิชาชีพ (**Internship**) ในสายงานพัฒนาซอฟต์แวร์หรือวิเคราะห์ข้อมูล[cite: 1]
