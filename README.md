### 👩‍💻 1. ข้อมูลส่วนตัวและเป้าหมายทางวิชาชีพ (Personal Profile & Career Objective)

สวัสดีค่ะ ดิฉัน **นางสาวภัควรรณ อินทสุวรรณ (ยูจีน / Ujeen)** ปัจจุบันกำลังศึกษาอยู่ชั้นปีที่ 2 **สาขาวิชาเทคโนโลยีสารสนเทศ (Information Technology)** คณะศิลปศาสตร์และวิทยาศาสตร์ **มหาวิทยาลัยเกษตรศาสตร์**

ดิฉันมีความหลงใหลและมุ่งมั่นอย่างยิ่งในด้าน **การเขียนโค้ดและการพัฒนาซอฟต์แวร์ (Coding & Software Development)** โดยให้ความสำคัญกับการออกแบบระบบที่มีโครงสร้างชัดเจน ใช้งานง่าย และสามารถแก้ไขปัญหาในชีวิตจริงได้อย่างมีประสิทธิภาพ ปัจจุบันดิฉันกำลังพัฒนาทักษะการเขียนโปรแกรมอย่างต่อเนื่อง ควบคู่กับการเรียนรู้ภาษาโปรแกรมมิงและเฟรมเวิร์กสมัยใหม่ เพื่อเตรียมความพร้อมสู่การทำงานจริงในสายอาชีพเทคโนโลยีสารสนเทศค่ะ

- **ชื่อ-นามสกุล:** นางสาวภัควรรณ อินทสุวรรณ (Pakkhawaran Inthasuwan)
- **ชื่อเล่น:** ยูจีน (Ujeen)
- **สถาบันการศึกษา:** สาขาวิชาเทคโนโลยีสารสนเทศ คณะศิลปศาสตร์และวิทยาศาสตร์ มหาวิทยาลัยเกษตรศาสตร์
- **ความสนใจหลัก:** การพัฒนาเว็บแอปพลิเคชันแบบ Full-Stack, การออกแบบฐานข้อมูล และการวิเคราะห์ข้อมูล
- **เป้าหมายทางวิชาชีพ:** กำลังเตรียมความพร้อมเพื่อเข้ารับการฝึกประสบการณ์วิชาชีพ (**Internship**) ในตำแหน่ง **Software Developer / Frontend Developer / Data Analyst** เพื่อนำความรู้จากการเรียนมาประยุกต์ใช้และเรียนรู้การทำงานร่วมกับทีมมืออาชีพ

### 🎓 2. ประวัติการศึกษาและพื้นฐานองค์ความรู้ (Education & Academic Background)

**ปริญญาตรี วิทยาศาสตรบัณฑิต (วท.บ.) สาขาวิชาเทคโนโลยีสารสนเทศ**  
*คณะศิลปศาสตร์และวิทยาศาสตร์ มหาวิทยาลัยเกษตรศาสตร์ (กำลังศึกษาอยู่ชั้นปีที่ 2)*

ตลอดระยะเวลาการศึกษา ดิฉันได้เรียนรู้และฝึกปฏิบัติในรายวิชาพื้นฐานสำคัญที่จำเป็นต่อการพัฒนาระบบซอฟต์แวร์ ได้แก่:
* **การเขียนโปรแกรมคอมพิวเตอร์ (Computer Programming):** หลักการคิดเชิงตรรกะ การเขียนโปรแกรมเชิงโครงสร้าง การแก้ไขปัญหาด้วยอัลกอริทึม และโครงสร้างข้อมูลพื้นฐาน
* **เทคโนโลยีเว็บและการออกแบบ (Web Technologies & UI/UX Design):** การพัฒนาเว็บไซต์สมัยใหม่ การจัดวางโครงสร้างหน้าเว็บให้รองรับทุกขนาดหน้าจอ และการออกแบบประสบการณ์ผู้ใช้งาน
* **ระบบจัดการฐานข้อมูล (Database Management Systems):** การวิเคราะห์และออกแบบฐานข้อมูลเชิงสัมพันธ์ (ER-Diagram, Normalization) และการจัดการข้อมูลด้วยคำสั่ง SQL
* **การวิเคราะห์และออกแบบระบบ (System Analysis & Design):** การเก็บความต้องการของผู้ใช้งาน การวางแผนโครงสร้างระบบ และการบริหารจัดการโครงงานซอฟต์แวร์

### 🌟 4. ทักษะการทำงานร่วมกับผู้อื่น (Soft Skills & Strengths)

* **ความกระตือรือร้นในการเรียนรู้ (Continuous Learner):** เปิดรับเทคโนโลยีและภาษาโปรแกรมมิงใหม่ๆ อยู่เสมอ สามารถศึกษาค้นคว้าด้วยตนเองและนำมาปรับใช้กับงานได้รวดเร็ว
* **การคิดวิเคราะห์และแก้ปัญหา (Analytical Thinking):** สามารถแยกแยะปัญหาที่ซับซ้อนออกเป็นส่วนย่อย และวางแผนแก้ไขได้อย่างเป็นระบบ
* **การทำงานเป็นทีมและการสื่อสาร (Teamwork & Communication):** มีประสบการณ์ทำงานกลุ่มในรายวิชา รับฟังความคิดเห็นของผู้อื่น และรับผิดชอบงานที่ได้รับมอบหมายจนสำเร็จตามเป้าหมาย
* **ความละเอียดรอบคอบ (Attention to Detail):** ใส่ใจในความถูกต้องของโค้ด โครงสร้างข้อมูล และความสวยงามเรียบร้อยของชิ้นงาน
